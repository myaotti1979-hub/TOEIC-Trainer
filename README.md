# TOEIC AI Trainer

AI生成問題で4技能（Listening / Reading / Speaking / Writing）を鍛えるTOEIC学習PWAアプリです。

## 🚀 セットアップ

### 1. アプリにアクセス

スマホのChromeで以下のURLを開いてください：

```
https://[your-github-username].github.io/toeic-trainer/
```

### 2. ホーム画面に追加

Chrome メニュー →「ホーム画面に追加」→ PWAとしてインストールされます。

### 3. APIキー設定

| キー | 取得先 | 用途 | 必須 |
|------|--------|------|------|
| Gemini API | [Google AI Studio](https://aistudio.google.com/apikey) | 問題生成・難易度判定・英作文添削 | 問題生成時のみ |
| Azure Speech | [Azure Portal](https://portal.azure.com) → Speech Service → キーとエンドポイント | ロールプレイ発音チェック | ロールプレイのみ |

- **Gemini API**: 無料枠で十分です。APIキー設定画面で入力。
- **Azure Speech**: S0（従量課金）推奨。月1000回の発音チェックで約$1.3。HOME画面の「🎭 Azure設定」から入力。
- **APIキーなしでも**ストック学習・単語帳・模試は利用できます。

### 4. 問題データのインポート

1. このリポジトリの [Releases](../../releases) ページを開く
2. 最新リリースからJSONファイルをダウンロード
3. アプリのHOME画面 →「📦+ 問題生成・管理」→「📥 インポート」
4. ダウンロードしたJSONを選択

> **ファイルサイズについて**: パートによって50MB前後に分割されています。1ファイルずつインポートしてください。

### 5. 難易度判定（推奨）

インポート後、問題管理画面の「🎯 未判定を判定」で難易度を付与すると、実力レベルに合った出題や推定スコアが正確になります。

> Gemini APIキーが必要です。1000問で約5-10分かかります。

## 📱 使い方

### HOME画面

| ボタン | 説明 |
|--------|------|
| ▶ 通常 | 全問題からタイプ分散シャッフル |
| 🆕 未回答 | 初見の問題だけ出題 |
| 🔥 苦手特訓 | 正答率70%未満のタイプのみ |
| 🎯 最適レベル | 推定スコア±150点の問題 |

### 回答前：自信度（任意）

💪自信あり / 🤔たぶん / 🎲カン をタップしてから回答すると、自信度分析に反映されます。

### 回答後の追加機能

| 機能 | 対象 | 説明 |
|------|------|------|
| 🎭 ロールプレイ | Part 3/4 | Azure発音チェック付き会話練習 |
| 🎙️ シャドーイング | Part 3/4 | 1文ずつ再生→真似る→確認 |
| ✍️ 英作文 | Part 5 | 同じ文法で英作文→Gemini添削（3軸採点） |
| 📖 WPM | Part 7 | 読速の自動計測 |

### 実力診断

HOME →「📊 実力診断」で以下が確認できます：

- IRT推定TOEICスコア（L/R内訳）
- パート別弱点タイプ
- 自信度分析（2×3マトリクス）
- 間違いパターン分析
- スピーキング診断（5軸レーダーチャート）
- ライティング診断（Grammar/Vocabulary/Relevance）

## ⚠️ 注意事項

- **APIキーは各自で管理してください**。他人に共有しないでください。
- **問題データはAI生成です**。ETS公式問題ではありません。
- **オフライン対応**: PWAとしてインストールすれば、問題の解答はオフラインで可能です（問題生成・添削にはネット接続が必要）。
- **データのバックアップ**: HOME →「📤 エクスポート」で学習データをバックアップできます。端末を変える場合はエクスポート→インポートで移行してください。
